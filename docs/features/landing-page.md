# Folio landing page

## Purpose

Help Markdown authors understand Folio's local desktop workflow: open a file, style physical pages, then print or save a PDF. Make the transformation tangible before asking visitors to install anything.

## Direction

Use the supplied Letters reference for a soft blue hero, generous white space, restrained blue details, and black pill actions. Make the page distinctly Folio through paper typography, a Markdown-to-document demonstration, and the existing six document themes.

## Delivery

- Add a separate `/landing.html` entry to the existing Vite project. Preserve the desktop app entry and behavior.
- Include an interactive sample with editable Markdown and the actual document-theme tokens, product capabilities, workflow, alpha availability, and FAQ.
- Link to the repository and alpha build instructions. Do not imply a public download or notarized release exists.
- Use responsive layouts, keyboard-accessible controls, visible focus, and reduced-motion support.
- Verify formatting, lint, existing frontend tests, production build, and browser desktop/mobile behavior.

## Scope

This is a marketing page, not another editor or a replacement for Folio's native print preview. Its interactive sample demonstrates rendering and theme choice; physical pagination and native export remain desktop capabilities. No accounts, analytics, or remote document processing.
